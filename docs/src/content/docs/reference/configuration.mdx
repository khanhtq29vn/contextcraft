## Assign settings in Python

```python
from contextcraft import Config, ContextCraft

config = Config(budget_tokens=8_000, focus_query="authentication")
pipeline = ContextCraft(config)
pipeline.config.focus_files = ["src/auth"]
```

The pipeline retains the supplied configuration and copies its settings before each run. List attributes return copies, so assign a new list instead of modifying a returned list.

## Output and tokenizer constants

`OutputFormat` exposes `MARKDOWN`, `XML`, and `JSON`. `TokenizerEncoding` exposes `GPT2`, `R50K_BASE`, `P50K_BASE`, `P50K_EDIT`, `CL100K_BASE`, `O200K_BASE`, and `O200K_HARMONY`.

These native constants are hashable, but are not Python `enum.Enum` members. Use `.as_str()` for their configuration or output labels.
